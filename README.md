# HEIR Cafe &amp; Events — Website

A conversion-focused, five-page marketing site for HEIR Cafe & Events: a cafe and
full-service event catering business offering a craft coffee bar, cafe kitchen and
bakery, mobile espresso catering, and wedding, corporate and private-party catering.

**Phone:** [(760) 900-7350](tel:+17609007350) · **Email:** [point4aj@gmail.com](mailto:point4aj@gmail.com)

## Stack

Vanilla HTML, CSS and JavaScript. No build step, no dependencies, no environment
variables and no external APIs. Open `index.html` in a browser, or serve the folder
statically (e.g. `python3 -m http.server`).

## Pages

| File | Purpose |
| --- | --- |
| `index.html` | Hero + CTA, services overview, why-us, booking process, reviews, FAQ |
| `services.html` | Coffee bar, cafe kitchen & bakery, mobile espresso bar, catering menus, add-ons |
| `events.html` | Weddings, corporate, private celebrations, package shapes, event FAQ |
| `about.html` | Story, values, who you work with, client quotes |
| `contact.html` | Contact details, quote request form, next steps, quick FAQ |

## Structure

```
index.html  services.html  events.html  about.html  contact.html
css/styles.css     all styling (design tokens, layout, components, responsive)
js/main.js         mobile nav, sticky header, scroll reveal, FAQ, form validation
assets/favicon.svg favicon placeholder (SVG coffee cup mark)
```

## Features

- Responsive layout from 320px up, with a fixed mobile "Call Now / Get a Quote" bar
- Click-to-call phone links in the top bar, nav, hero, every CTA band and the footer
- Quote form with client-side validation and a honeypot field; on submit it opens the
  visitor's mail client pre-filled and addressed to the business (no backend required)
- Accessible markup: semantic landmarks, skip link, ARIA labels, visible focus states,
  `prefers-reduced-motion` support
- SEO: per-page title/description/keywords, canonical, Open Graph and Twitter cards,
  plus `CafeOrCoffeeShop` JSON-LD structured data on the home page
